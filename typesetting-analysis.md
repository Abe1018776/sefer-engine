## Page-by-Page Typesetting Decisions

### Page 103 (Gate Title) — Full decorative page
- Ornamental oval frame with "שער ההודאה" in display font
- Lists all 3 chapter titles: פרק א, פרק ב, פרק ג
- **Decision**: Always a full standalone page, no content

### Page 104 — Blank verso
- Standard blank page after gate title (recto/verso convention)

### Page 105 (עז) — Chapter opener
- **Layout**: ~40% body / ~60% footnotes
- Decorative "פרק א" banner with nikudded title "הַשִּׁיר וְהַשֶּׁבַח לְחַי עוֹלָמִים"
- Sub-header for entry א + body text (~8 lines bold)
- Two footnote columns: FN[1] partial + EN[1] partial
- **Decision**: Chapter openers get generous body space. Typesetter doesn't cram — leaves room for the decorative header. Footnotes start on the same page as their anchor but are allowed to overflow.

### Page 106 (עח) — Footnote continuation (NO body text)
- **Layout**: 0% body / 100% footnotes
- ENTIRE page is FN[1] and EN[1] continuation
- Both columns run full page height, roughly balanced
- **Decision**: When footnotes are very long, the typesetter lets them consume a full page. No body text is forced onto this page.

### Page 107 (עט) — Mixed body + footnotes
- **Layout**: ~15% body / ~85% footnotes
- Sub-header "הודאה לה' - על שחפץ בשבח שפלים כמונו" + entry ב body (~5 lines)
- Two columns: FN[2] + EN[2] start
- **Decision**: Even with very little body, the sub-header + entry marker are kept together. The typesetter never puts a sub-header at the bottom of a page without its entry following.

### Page 108 (פ) — Footnote continuation + body mix

## Typesetting Rules Extracted

### Rule 1: Footnote-to-Body Ratio is Driven by Content, Not Fixed
The body/footnote split ranges from 0%/100% to 45%/55%. There is NO fixed ratio. The typesetter lets footnotes take whatever space they need, and body text gets the remainder.

### Rule 2: Footnotes Can Consume Entire Pages
When a single entry's footnotes are very long (e.g., FN[1] + EN[1] for entry א), the typesetter allows them to span a full page with zero body text. This happens on page 106.

### Rule 3: Sub-headers Are Never Stranded
A sub-header line ALWAYS appears with at least 2-3 lines of its entry body on the same page. The typesetter never puts a sub-header at the page bottom with its body starting on the next page.

### Rule 4: Chapter Endings Get Whitespace
When a chapter (פרק) ends, the typesetter places a decorative ornament and leaves deliberate whitespace below. The page is NOT filled to capacity. This creates visual separation between chapters.

### Rule 5: Chapter Openers Get Decorative Headers
Each פרק starts with a decorative banner containing the chapter number and a nikudded (vowelized) title. This takes approximately 15-20% of the page height.

### Rule 6: L-Shape Triggers on Imbalance > ~1.4:1
When one footnote column is significantly longer than the other (roughly 40%+ longer), the typesetter uses the L-shape layout where the shorter column ends and the longer one continues full-width below.

### Rule 7: Single Column When Only One Footnote Type
When an entry has only מקור and no צינור (or vice versa), the typesetter uses a single full-width column at the bottom — NOT a half-width column with empty space beside it.

### Rule 8: Multiple Footnote Entries Per Column Are Bundled
When a body entry has two footnote references (e.g., FN[14] and FN[15] for entry ג), both go in the מקור column together. Similarly, multiple endnotes (EN[6] and EN[7]) go in the צינור column together.

### Rule 9: Footnotes Stay With Their Body Entry's Page (±1)
A footnote always appears on the same page as its body entry anchor, or at most on the immediately following page. The typesetter never lets footnotes drift more than 1 page from their anchor.

### Rule 10: Even/Odd Header Convention
- Odd pages (recto): "פרק [letter]" in center
- Even pages (verso): "שער ההודאה" in center
- Both pages: "שפע" right, "שלמה" left, Hebrew page number on outer edge

### Rule 11: Page Fill Target is ~90-100%
On regular (non-chapter-ending) pages, the typesetter fills pages to near capacity. Slack of more than ~15% only appears at chapter boundaries. The average content page is 90-95% filled.

### Rule 12: The Divider Line Separates Body from Footnotes
A thin rule with a diamond ornament separates the body zone from the footnote zone. This appears on every page that has footnotes, regardless of how much body text is present.

## Implications for the Solver

1. **Zero-body pages must be supported** — the solver must allow pages where only footnotes appear
2. **Footnote volume drives the split** — budget should be allocated footnotes-first, body-second
3. **Single-column mode needed** — when only one footnote type exists, switch from two-column to single full-width
4. **Chapter boundary detection** — insert whitespace + ornament at פרק transitions
5. **Sub-header anchoring** — hard constraint: sub-header + ≥2 body lines must stay together
6. **Footnote bundling** — multiple FN refs for one entry must stay in the same column on the same page
7. **L-shape threshold** — trigger at ~1.4:1 column ratio, with full-width overflow for the longer column
8. **Page fill target** — badness function should target 90-95% fill on regular pages, allow 50-75% on chapter endings
